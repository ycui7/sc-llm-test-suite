# Histogram chart — generation requirements

The missed-needle histogram rendered by `qc_hist.py` must satisfy every rule
below. These were iterated on live and are the acceptance criteria; future
edits to the renderer must preserve them.

## Data semantics

- Plots **MISSED needles only** (primary and only series). Retrieved needles
  are NOT drawn; a blank column means that bin was clean.
- 2048 random-unique needles (unique word + unique 5-digit number, no shared
  words), pinned RNG seed for reproducibility.
- Needles are planted **uniformly across the tested span**: one needle per
  stratum, jittered inside the stratum (no depth clustering).
- The x span covers **3/4 of the served context** (the qualification bar —
  needles are embedded within 0 .. ctx*0.75), never beyond it. For ctx =
  1,048,576 the axis ends at 768K.

## Geometry

- x axis: 64 equal bins (bin = span/64 tokens).
- y axis: 32 logical rows, **1 row = 1 missed needle**, fixed scale
  saturating at 32 (the uniform 2048/64 reference height). No autoscaling.
- Row labels shown at 8/16/24/32.

## Rendering

- Generated by `qc_hist.py` (Python 3, stdlib only). No manual drawing.
- Sub-cell packing instead of braille: each text line carries 2 logical
  rows via half-blocks (`▀` upper, `▄` lower, `█` both, blank=neither) so
  the 32-row scale fits in 16 lines. Braille (U+2800–U+28FF) is banned:
  font fallback rendered empty vs filled cells at different advances and
  broke vertical alignment.
- ONE glyph family inside the box: ASCII + `▀▄█` (U+2580–U+258F) +
  **single-line box drawing only** (`─│┌┐└┘├┤┬┴`, U+2500–U+253F block).
  Double-line characters (U+2550+) are banned outright.
- x ticks on the axis rule: major `┴` at binary **token milestones**
  (64K, 128K, 256K, 512K for a 768K span) mapped onto the linear axis, plus
  a forced major at the span end; minor `┬` every 4 bins. Minimum tick
  increment 8K depending on full context length (`_milestones()`: base =
  smallest 8K·2^k with base·12 ≥ span).
- Token labels (`0, 64K, 128K, 256K, 512K, 768K`) sit **below the x-axis
  line, unbordered**, each ending at the exact plot column of its `┴` stem.
- The bordered box contains ONLY the title block (3 header rows) and the
  bar field; the border closes AT the x-axis (`└` / `┘` corners on the tick
  rule). Nothing is bordered below the axis.
- Title/header: 3 rows inside the box, to the right of the Y-axis gutter
  (identity line, ctx/seed/elapsed line, score/scale line).
- NO legend, NO per-bin count dump, NO footnotes below the chart.

## Alignment guarantees (structural, not eyeballed)

- Every bordered row is produced by one constructor, `_row(gutter, left,
  body, right)`, with a single fixed gutter width reserved on EVERY line
  (label field = `len(str(ROWS))+1`), so nothing can shift left of the
  Y-axis and the top border can't ignore it.
- `render()` builds the complete line list first, then `_check()` asserts:
  (a) every bordered line has exactly the same column width, (b) every
  character is within the allowed glyph whitelist. Violations raise before
  anything prints — alignment cannot regress silently.

## Suite spec (chart's consumer, `test_needles.py`)

- Gate: 2048 needles, uniform placement, tested span = 3/4 ctx, output turn
  budget = 1/4 of the full served context per turn (`--turn-tokens` default
  `ctx//4`), probes at max_tokens ≥ 4096 (32768 default suite-wide).
- Chart is printed at run end and saved as `needles.histogram.txt` beside
  `needles.json`; per-bin counts remain available in JSON for machines.
